# CGPA Prediction Tool

A web-based tool that predicts future CGPA using **Lagrange Interpolation**.

## Features

- CGPA prediction
- Dynamic semester input
- Confidence indicator
- CGPA trend graph

## Technologies

- HTML
- CSS
- JavaScript
- Chart.js

## How it works

The tool uses **Lagrange Polynomial Interpolation** to estimate CGPA based on previous semester results.
